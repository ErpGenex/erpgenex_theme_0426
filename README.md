# ERPGENEX Theme 0426

Desk theme bundle for **ERPGENEX** on Frappe (v15+). Includes the ERPGENEX design system and a thin compatibility layer inspired by [business_theme_v14](https://github.com/Midocean-Technologies/business_theme_v14) (MIT).

Use with **omnexa_theme_manager** (tenant presets, Theme Studio, API) or install this app alone for the visual layer only.

## Site config

`bench set-config disable_omnexa_desk_theme 1` — disables this desk theme (stock Frappe desk).
